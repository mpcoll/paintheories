# Pain Knowledge (repo: paintheories) — notes for Claude

Astro 7 static site on GitHub Pages with custom domain https://painknowledge.com (base `/`, DNS via Cloudflare). Portal home at `/`; the Pain Theories module lives under `/theories/` (overview, all, map, timeline, compare, evidence, gaps); mechanisms, references, search, about and data are portal-wide. Old top-level URLs (/map/ etc.) are redirect stubs. See PLAN.md.

- Content: `src/content/theories/*.md`, `src/content/mechanisms/*.md`, bibliography in
  `src/data/references.yaml`. Schema in `src/content.config.ts`; vocabularies in `src/data/taxonomy.ts`.
- Never invent references. Add DOIs with `npm run ref:add -- <doi>` (Crossref) and check
  that the returned title/authors match the intended paper. Works without DOIs get
  `source: manual`. Only cite claims that the cited source supports.
- Pain Biology module at `/biology/` (sub-nav: Pain circuits, Nociceptors & gate, Sensitization, Neuroimaging, Mechanisms). `/biology/imaging/` (acute experimental pain first; chronic pain to come): methods (`src/data/imaging-methods.yaml`, `ResolutionChart`; resolution boxes are approximate orders of magnitude), real Neurosynth maps embedded from Planum (`PainMapExplorer`, `planumFunctionLink` in planum.ts: `function=pain`, `term:<term>` or `compare:a,b`, atlas hcp-mmp; embed, never copy), reverse-inference demo (`ReverseInference`, illustrative numbers), LEP figure (`LepFigure`, latencies from hu2014), findings (`src/data/imaging-findings.yaml`, collection `imagingFindings`, linked from circuit stations and theories) and signatures (`src/data/pain-signatures.yaml`; state availability exactly as the developers publish it). `/biology/sensitization/`: allodynia/hyperalgesia curve (`SensitizationCurve`, schematic), primary/secondary hyperalgesia zones (`HyperalgesiaZones`, areas from LaMotte 1991), inflammatory mediators (`src/data/inflammatory-mediators.yaml`, collection `inflammatoryMediators`, figure `InflammationFigure`). `/biology/periphery/`: fibre classes (`src/data/fibre-types.yaml`, collection `fibreTypes`), transducers (`transducers.yaml`), gate simulator scenarios in `src/components/GateSimulator.astro` (qualitative teaching model; cite sources per scenario). Circuit figure data: `src/data/circuit-stations.yaml` and `circuit-pathways.yaml` (collections `circuitStations`, `circuitPathways`); every pathway edge carries its own `note` and `refs` (prefer tract-tracing sources; say when evidence is only functional; `reciprocal: true` draws both arrowheads); each station maps to a Planum region id (https://planumatlas.com, manifest at planumatlas.com/models/cdmd/manifest.json). Links/embeds via `src/lib/planum.ts` (`embed=1` iframes); multi-parcel structures use `planum.mark` (all parts highlighted). Run `npm run planum:check` after editing stations (ids exist, right atlas, drawable). Do not copy Planum renders into this repo: its data layers carry mixed licences (some non-commercial).
- Pain Conditions module at `/conditions/` (sub-nav: Overview, Prevalence, ICD-11, Mechanisms, Crosswalk; chronic conditions only). Entries in `src/content/conditions/*.md` (schema `conditions`), vocabularies in `src/data/conditions-taxonomy.ts` (traditional families, body-map regions, ICD-11 MG30 tree + extension codes, IASP descriptors and roles). Each entry has `icd.pain` (MG30 codes; `when` for conditional mappings; optional per-code `descriptors`), `icd.condition` ("code also" disease codes), descriptors with role (defining/common/subset) and refs, prevalence with source and population (plus `prevalence.chart`: numbers for the /conditions/prevalence/ chart; `basis` population vs group, never mixed on one axis; `derived: true` for our own calculations), criteria. ICD-11 codes/titles must match the WHO release exactly: run `npm run icd:check` (downloads the WHO 2026-01 tabulation to node_modules/.cache; never commit WHO files). Mapping claims cite `who2026` plus the IASP Task Force paper for the category (treede2019, nicholas2019, bennett2019, schug2019, perrot2019, aziz2019, scholz2019, benoliel2019).
- Pain Treatments module at `/treatments/` (sub-nav: Overview, Evidence map, Guidelines, Reading the evidence). Entries in `src/content/treatments/*.md` (schema `treatments`), vocabularies in `src/data/treatments-taxonomy.ts` (modalities, targets = where it acts, condition GROUPS linked to condition ids, effect sizes, GRADE certainty, recommendations, GUIDELINES with their reference keys). Evidence records give the effect exactly as the source reports it; `size` follows the fixed rules on /treatments/reading-evidence/ (NNT ≤4 large, >4–7 moderate, >7 small; SMD 0.8/0.5/0.2). Guideline records map the guideline's own wording (NICE "offer" → strong-for, "consider" → weak-for, "do not offer/initiate" → against) and quote it in `note`; check NICE text against the current guideline page (NG59 was updated July 2026 and removed some recommendations). Teaching and research summary, not medical advice.
- Pain Assessment module at `/assessment/` (sub-nav: Overview, Core outcomes, Meaningful change, Psychophysics). Entries in `src/content/instruments/*.md` (schema `instruments`), vocabularies in `src/data/assessment-taxonomy.ts` (categories = how it measures, constructs = what, populations, IMMPACT domains from turk2003, COSMIN property kinds, availability). Measurement properties give values exactly as the source reports them, with the sample (`population`); MIC values only from a source that reports them for that instrument. `availability` states terms ONLY from the developer's or licence holder's page (quote it in `note`, link it in `url`); test procedures use `method`; if unconfirmed use `unclear`. Never reproduce questionnaire items. `immpact` only for measures IMMPACT recommends (dworkin2005/dworkin2008). Meaningful-change calculator uses farrar2001 (about 2 points or 30%) and moore2010 tiers (15/30/50/70%); the QST profiles on /assessment/psychophysics/ are illustrative z-scores shaped after baron2017 clusters.
- Bibliometrics: `src/data/citations.json` (OpenAlex counts per reference, refreshed with `npm run citations:fetch`; commit the result). `src/lib/metrics.ts` derives per-theory citations (founding works) and map influence (incoming relations); `SizeToggle` sizes markers on /theories/ and /theories/map/ (?size=citations|influence).
- Open questions / gaps: `src/content/gaps/*.md` (schema `gaps` in content.config.ts); each lists ≥2 theories' competing predictions and a decisive test. Rendered at /gaps/ together with an automatic coverage analysis.
- Writing conventions and the evidence format: docs/CONTENT_GUIDE.md.
- New or substantially changed entries get `review: draft`; only the owner sets `reviewed`.
- Cite in body text with `[@key]` (remark plugin `src/scripts/remark-citations.mjs`; unknown keys fail the build).
- Internal links must go through `url()` from `src/lib/data.ts` (base path).
- Before committing: `npm run check && npm run build`.
- Map colours: 5 domain slots validated for CVD in light and dark; domain shape is the
  secondary channel. Don't add a sixth domain without revisiting this.
